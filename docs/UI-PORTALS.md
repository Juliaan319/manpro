# Pembaruan UI portal

- `/` adalah halaman publik dengan hero foto, informasi laboratorium, layanan, dan panduan.
- `/mahasiswa` mengarahkan ke login mahasiswa bila belum masuk. Akun USER memperoleh dasbor khusus dengan daftar PC, pengajuan reservasi, riwayat pribadi, dan akses presensi.
- `/admin` adalah pintu masuk pengelola. Wewenang tetap berdasarkan peran akun database; tautan portal tidak memberikan hak administrator.
- Portal memakai satu sidebar, dengan menu ponsel. Navigasi publik disederhanakan dan mempunyai menu ponsel tersendiri.
- Referensi arah visual: https://web-smith.de/ — hierarki judul besar, pembagian hero, layanan berbentuk kartu, dan CTA yang jelas. Konten disesuaikan dengan laboratorium Petra.
